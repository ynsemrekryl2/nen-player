# Language detection fixtures

Bu dizindeki bütün subtitle cümleleri NEN-020 testleri için üretilmiştir;
gerçek film veya dizi diyaloğu içermez. Her `.srt` dosyasının beklenen kanonik
`LanguageTag` sonucu yanındaki `.language.golden` dosyasındadır. `unknown`,
güven eşiğini geçmeyen ve `Dil Belirsiz` grubuna gidecek belgeyi gösterir.
